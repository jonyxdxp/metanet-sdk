 REQUEST FOR COMMENTS


 A Request for Comments (RFC) is a publication in a series from the principal technical development and standards-setting bodies for the Internet



 An RFC is authored by individuals or groups of engineers and computer scientists in the form of a memorandum describing methods, behaviors, research, or innovations applicable to the working of the Internet and Internet-connected systems. It is submitted either for peer review or to convey new concepts, information, or, occasionally, engineering humor




 Internet Standard (often abbreviated STD) is the highest maturity level in the Internet Engineering Task Force (IETF) standards track for Internet protocol specifications. Internet Standards are published as one or more Request for Comments (RFC) documents and are additionally assigned an STD number that identifies the standard as a whole (as distinct from the RFC document number)
